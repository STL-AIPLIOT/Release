### 추가 패널 — `pursuit vs position` 겹침

- 노랑 = `ep_reward_pursuit`, 파랑 = `ep_reward_position`, 초록 = 차이(pursuit − position)
- 0 기준선을 점선으로 깔고, **두 계열이 모두 있을 때만** 차이선을 그린다

```diff
# tools/log_analysis/schemas.py
 DASHBOARD_METRICS = (
     "reward_mean", "crash_rate", "ep_min_distance", "ep_wez_steps", "win_rate",
+    "ep_reward_pursuit", "ep_reward_position",
 )
+DASHBOARD_COMBOS = (
+    ("ep_reward_pursuit", "ep_reward_position", "pursuit vs position"),
+)

# tools/dashboard.py
+ap.add_argument("--logdir", "--training-logdir", dest="logdir", type=Path, ...)
+for(const [a,b,label] of (d.combos||[])) addComboCard(g, run, a, b, label);
+# addComboCard() : 없는 계열은 사유와 함께 N/A 표시, 있는 계열만 그림
+# drawCombo()    : 0 기준선 + 두 계열 + 차이선
+# suggest_logdir(): training_log.csv 를 못 찾으면 실제 경로를 안내
```

### 상쇄 판독법

1. 초록 차이선이 **0 기준선에 붙으면** pursuit 와 position 이 서로 상쇄 중이다
   (헤드온에서 pursuit 가 벌고 position 이 까먹는 구간).
2. 노랑이 양수인데 초록이 0 근처면 "정렬 보상은 받는데 위치 이득이 없다" —
   실교전으로 이어지지 않는 shaping 구간이다.

현재는 `position` 이 로그에 없어 패널이 pursuit 단독 + `로그에 없는 컬럼: ep_reward_position`
경고를 띄운다. `_CSV_FIELDS` 에 추가되는 즉시 차이선이 자동으로 그려진다.

> 16 km 밖에서도 지급된다는 점이다.
